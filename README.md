# ORDER-AI — MICCAI 2026 Tutorial

## Learning with Order: Ordinal Representations for Trustworthy Medical AI

**1 October 2026 · Strasbourg, France**

[Official tutorial website](https://learningwithorder.github.io/)

This repository contains slides from the ORDER-AI tutorial at MICCAI 2026.

The tutorial examines how to incorporate ordinal structure into medical AI,
from classification and segmentation to evaluation metrics, representation
learning and generative AI.
